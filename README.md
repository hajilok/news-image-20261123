# World News — Monday, 23 November 2026 (`news-image-20261123`)

An illustrated single-image global news summary for **Monday, 23 November 2026**, submitted to the [make.fun `news-image-20261123` competition](https://make.fun/r/41fw6r6c).

## Run

Requires Node 22 (standard library only, zero external dependencies):

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` verifies the integrity, pixel dimensions (`<= 1024x1024`), and size cap (`<= 1 MiB`) of `entry.png`, then writes identical bytes deterministically to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
